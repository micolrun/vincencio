# ADR-0003: Firebase 계정별 제작 상태 동기화

**Status:** Accepted  
**Date:** 2026-08-30  
**Deciders:** 프로젝트 소유자

## Context

제작자는 여러 컴퓨터에서 동일한 등장인물 보관함과 영상 프로젝트를 이어서 사용해야 한다. 기존 브라우저 저장소만으로는 기기 간 동기화와 복구가 되지 않는다.

## Decision

- Firebase Authentication으로 확인된 사용자별로 Cloud Firestore `users/{uid}/studio/state` 문서를 사용한다.
- 문서에는 인물 보관함, 입력값, 프로젝트 장면표, 자막, 검토 기록, 글꼴과 이미지 프롬프트 설정을 저장한다.
- 음성 원본·렌더링 영상·서비스 계정 키는 자동 업로드하지 않는다.
- Firestore 규칙은 인증된 사용자가 자기 UID 경로만 읽고 쓸 수 있게 제한한다.
- 브라우저 저장소는 오프라인/동기화 실패 시의 임시 사본으로 유지한다.

## Consequences

- 같은 Google 계정으로 로그인하면 다른 컴퓨터에서도 최근 프로젝트와 인물 보관함을 불러올 수 있다.
- Firestore를 처음 만들고 저장소 규칙을 배포해야 한다.
- 대용량 음성·영상 보관이 필요해지면 별도의 Firebase Storage 정책과 비용 한도를 설계해야 한다.
